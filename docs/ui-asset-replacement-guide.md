# 首页图片素材替换说明入口

首页唯一人工维护来源为 `design/home-index-elements.json`。当前素材路径、默认图映射、显示尺寸及图片操作均以生成的[首页布局控制指南](home-layout-controls-guide.md)为准；本文不再维护独立尺寸推导或手改 WXML/WXSS 的替换步骤。

## 素材调整入口

- 背景、按钮底图、推荐内外框、封面、图标及标签底图：按新指南的元素清单定位对应 `designId`。
- 换图、隐藏、清除和恢复默认图是不同操作，按新指南的“图片操作”配置；不要直接修改生成节点的 `src` 或样式。
- 素材路径或布局配置变更后的生成与只读校验流程，见新指南“生成与校验”；不要手改生成指南。

## 当前素材限制

- 背景包含内嵌按钮、标题、推荐框、封面和装饰，并非无文字背景；独立节点开关无法删除这些背景像素，移除它们需要处理背景素材本身。
- 独立按钮底图、文字、图标和点击范围分别控制，换底图不等于修改点击范围。
- 放大镜字符和标签底色只是临时回退，不是最终图片；填写对应图片路径的方式见新指南。
- 首页固定单屏，越界裁切，不通过滚动解决；素材应结合新指南中的当前配置及设备可用窗口验收，不再使用旧按钮宽高推导制作图片。
- 按钮初始命中范围尚未真机测量；不同机型裁切、文字重叠、点击与轮播、tabBar / 安全区适配仍待 DevTools 和真机验证。

## 业务边界

- 素材与布局调整不修改云函数、AI、service、数据库、路由或 tabBar 配置。
- 保留 `goToExplore`、`goToRecommendation`、推荐数据绑定及稳定 `designId`；图片替换不改变推荐业务逻辑。
