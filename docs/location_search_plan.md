# 地点搜索方案冻结

## 1. 文档目的

本文档用于冻结《此地有传说》地点入口的产品方案、数据契约和架构边界。

本文档只描述：

- 当前已实现的推荐地点与临时本地筛选
- 微信原生地点选择的候选方案与验证边界
- 未来地点标准化、复用与落库边界

本文档不代表当前代码已经接入外部 POI 搜索服务。

---

## 2. 当前实现与当前结论

### 2.1 当前已实现

当前 `discovery` 页已经实现稳定入口与一个临时过渡能力：

1. 默认展示系统推荐地点
2. 对当前已加载的推荐地点做本地关键词筛选

当前代码的真实来源：

- 推荐地点来自 CloudBase `locations` 集合
- 查询条件为 `status = "published"`
- 页面加载时读取最近已发布地点
- 搜索框只对页面内存中的 `allLocations` 做本地筛选

### 2.2 当前实现的准确定位

当前本地筛选只是临时阶段能力，不能称为：

- 全国地点搜索
- 地图搜索
- POI 搜索
- 外部地点搜索

当前本地筛选的作用仅是帮助用户在“已经加载到页面的推荐地点”里更快定位目标地点。

### 2.3 当前阶段结论

当前项目决定：

1. 保留系统推荐地点
2. 保留对已加载推荐地点的本地关键词筛选
3. 不依赖腾讯位置服务 WebService / API Key
4. 用微信原生 `wx.choosePoi` / `wx.chooseLocation` 验证“用户主动选择地点”是否可作为候选入口
5. 当前不实现全国 POI 文本搜索

### 2.4 当前验证范围

本轮只验证：

- 微信原生 `wx.choosePoi`
- 微信原生 `wx.chooseLocation`
- 是否需要 `requiredPrivateInfos`
- 是否需要 `scope.userLocation` 相关声明
- 是否需要后台接口权限与隐私声明

本轮不执行：

- API Key 申请
- 腾讯位置服务 WebService 接入
- 云函数代理地点搜索
- 全国 POI 文本搜索

---

## 3. 两种地点来源

## 3.1 A. 系统推荐地点

### 当前阶段来源

- CloudBase `locations` 集合
- 当前已发布的 `locations`
- 页面进入时默认展示
- 搜索框为空时恢复展示
- 这些地点可以是人工维护的推荐地点

### 在最终产品中的地位

这一层在最终产品中仍然保留，用于：

- 提供默认入口
- 承接运营推荐
- 提供稳定可探索的地点池

### 当前与未来共同约束

- 推荐地点必须是系统认可的可展示地点
- 推荐地点进入 `location` 页时仍然使用真实 `locations._id`
- 推荐地点不能和外部搜索结果混为同一种数据来源描述

---

## 3.2 B. 用户主动选点结果

### 当前候选来源

- 微信原生 `wx.choosePoi`
- 微信原生 `wx.chooseLocation`
- 用户在微信原生界面中主动选择地点

### 当前用途边界

- 用于验证真实设备是否能拉起原生地点选择能力
- 用于验证返回字段是否能支撑后续 UGC 地点输入
- 不等同于全国 POI 文本搜索
- 不等同于自定义外部地点搜索 API

### 当前冻结结论

- 当前本地筛选仍然只是临时能力
- 微信原生选点是“用户主动选择地点”的候选入口
- 微信原生选点不替代推荐地点列表
- 清空关键词时仍然回到系统推荐地点列表

---

## 4. 最终页面状态

地点页入口的最终状态机冻结如下：

### 4.1 初始状态

- 显示系统推荐地点
- 不显示外部搜索结果

### 4.2 用户输入关键词

- 当前仍只做推荐地点本地筛选
- 不进入全国 POI 文本搜索
- 不发起腾讯位置服务 WebService 请求

### 4.3 用户主动选点

- 通过微信原生 `wx.choosePoi` 或 `wx.chooseLocation` 打开地点选择界面
- 返回用户明确选中的地点信息
- 如果调用失败，应展示真实错误，不伪装成“没有结果”

### 4.4 选点成功

- 返回微信原生能力提供的地点字段
- 当前重点关注 `name`、`address`、`city`、`latitude`、`longitude`、`type`
- 当前不自动创建正式 `locations` 记录

### 4.5 选点取消或失败

- 显示真实 `errMsg`
- 明确区分用户取消、权限未开通、隐私声明缺失和其他失败

### 4.6 推荐地点链路保持不变

- 不把微信原生选点结果混入推荐地点列表
- 不影响当前 `discovery -> location -> story` 链路

### 4.7 清空关键词

- 返回系统推荐地点
- 不把筛选结果或原生选点结果混入推荐列表

---

## 5. 地点身份和去重规则

### 5.1 微信原生选点身份边界

微信原生 `wx.choosePoi` / `wx.chooseLocation` 返回的是用户选中的地点信息，不等同于自定义外部 POI 搜索结果。

冻结规则：

1. 当前不把微信返回结果伪装成 `providerPlaceId`
2. 当前不自动创建新的 `locations` 记录
3. 当前只验证返回字段和权限要求
4. 后续如需落库，必须先定义标准化与去重规则

### 5.2 当前代码保持不变的规则

- 业务代码不得依赖固定 `_id` 前缀或固定长度
- `stories.locationId` 必须继续指向真实 `locations._id`

### 5.3 后续 UGC 候选字段

后续如果用户通过微信原生选点创建 UGC 地点，当前优先保留这些字段：

- `name`
- `address`
- `city`
- `latitude`
- `longitude`

在正式去重规则确定前，不得直接把名称字符串当作稳定地点身份。

## 7. 未来搜索架构边界

### 7.1 当前安全边界

冻结规则如下：

- 当前不依赖腾讯位置服务 WebService / API Key
- 不调用 CloudBase 云函数地点搜索
- 小程序前端不拼接腾讯地点搜索 URL
- 当前验证只调用微信原生 `wx.choosePoi` / `wx.chooseLocation`
- 当前不写入 CloudBase

### 7.2 当前职责划分

前端小程序负责：

- 展示推荐地点
- 对推荐地点做本地筛选
- 在临时测试页直接调用微信原生地点选择能力
- 展示成功字段和失败信息

当前不需要：

- 云函数代理地点搜索
- 腾讯位置服务 API Key
- 外部 POI 文本搜索服务

## 8. 本地筛选、原生选点与附近能力

这三类能力必须明确拆分，不能写成同一个功能。

## 8.1 推荐地点本地筛选

定义：

- 用户输入关键词后，只在当前已加载推荐地点中做本地筛选

特点：

- 不请求外部 POI 服务
- 不需要 API Key
- 不创建新地点
- 不改变现有 `locations._id`

当前状态：

- 已实现
- 继续保留

## 8.2 微信原生地点选择

定义：

- 用户通过微信原生界面主动选择一个地点

特点：

- 候选接口为 `wx.choosePoi` / `wx.chooseLocation`
- 返回的是用户选择的地点信息
- 可能涉及 `requiredPrivateInfos`、`scope.userLocation`、隐私声明和后台接口权限
- 不等同于全国 POI 文本搜索

当前状态：

- 正在通过临时测试页验证
- 尚未接入正式业务流程

## 8.3 附近地点能力

定义：

- 基于用户当前位置或地图附近范围选择地点

特点：

- 需要额外权限与真机验证
- 可能涉及定位授权、地图能力和类目审核

当前状态：

- 当前暂不实现
- 不应与本地筛选或原生选点合并描述

## 9. 与当前代码的关系

### 9.1 当前推荐地点链路

当前代码中的推荐地点链路是：

首页
-> `discovery`
-> CloudBase `locations`
-> `location`

### 9.2 当前本地筛选的定位

当前 `discovery` 页里的搜索框：

- 只筛选当前已经加载的 `allLocations`
- 不会创建新地点
- 不会改变 `locations._id`
- 点击结果后仍进入原有 `location` 页面

它在最终产品中的定位是：

- 临时过渡能力
- 方便用户在推荐地点里快速定位
- 不是全国 POI 文本搜索能力

### 9.3 当前微信原生选点的定位

当前新增的临时测试页只用于：

- 验证 `wx.choosePoi` / `wx.chooseLocation` 能否在真实设备上打开
- 采集成功字段与失败信息
- 评估后续 UGC 或新故事入口是否适合接入

它当前不承担：

- 推荐地点搜索
- 外部 POI 文本搜索
- `locations` 自动落库
- 正式业务流程跳转

---

## 10. 暂不实现清单

以下能力本轮仅冻结方案，不进入实现：

- 全国 POI 文本搜索
- 腾讯位置服务真实 API 接入
- 云函数或后端代理接口
- 未预存地点的自动落库
- 地点标准化流水线
- POI 去重与地点合并
- 附近地点搜索
- 地理位置授权
- 微信原生选点结果接入正式 UGC / 故事入口
