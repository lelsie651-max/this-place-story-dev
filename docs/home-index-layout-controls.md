# 首页布局说明入口

本文仅保留旧链接入口，不再独立维护首页布局数字、选择器或手改 WXML/WXSS 的步骤。

- 唯一人工维护来源：`design/home-index-elements.json`。
- 当前生成指南：[首页布局控制指南](home-layout-controls-guide.md)。坐标、父子关系、显隐、素材路径、文字及生成校验均以该指南为准。
- 首页 WXML/WXSS 与指南由生成器输出，不要手改生成文件，也不要通过更换根节点 class 恢复旧首页布局。

## 当前模式与限制

- 品牌首页固定单屏，越界裁切，不通过滚动解决。
- 背景已内嵌按钮、标题、推荐框、封面和装饰；隐藏独立节点不能删除背景像素。
- 放大镜字符与标签底色是临时方案，图片替换按新指南操作。
- 按钮命中范围来自旧样式推导，尚未真机测量；不同机型的裁切、点击与 tabBar / 安全区适配仍待验证。
- 保留 `goToExplore`、`goToRecommendation` 及推荐业务数据，不以布局调整改动业务逻辑。
